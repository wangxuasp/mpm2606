# Extech MPMS P5 审批与更改设计规格

> 文档编号：MBD-MES-P5-SPEC-01 | 日期：2026-06-23  
> 依据：总方案 §3.11–3.13 | 前置：P4 完成

## 1. 目标

**审批/更改闭环**：7 类工作流模板、审批中心、工艺更改 3 步向导、更改汇总导出。

## 2. 范围

### 纳入
- XState 工作流引擎 + 7 模板定义
- `workflow-service`：发起、流转、guard 校验、受控发布
- 审批中心：待办/已办、流程时间线、通过/驳回
- MBOM/BOP/工艺文件 提交审批入口
- 工艺更改 3 步向导（基本信息→diff 影响分析→通知）
- 更改汇总筛选 + Excel 导出
- 系统管理：工作流模板只读列表

### 不纳入（→ P6/P7）
- 工艺汇总清单
- 三维 JT
- AI Copilot

## 3. 成功标准

- [ ] 7 模板可在 admin 查看
- [ ] 可对 MBOM 根/BOP 根提交审批并流转至受控
- [ ] guard 失败阻断（外购件下级约束）
- [ ] 更改单向导可创建并提交
- [ ] 更改汇总可筛选导出
- [ ] `pnpm build` 通过
